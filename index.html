What is the Bulk URL Status Checker?

Paste up to 1,000 URLs and get every HTTP status code in a single run — which pages are live (200), which have moved (301 / 302), which are dead (404), and which are hiding behind bot protection. Every live page also reports SEO signals: its page title, noindex / nofollow flags, and canonical URL. Results can be searched, filtered, and exported to Excel, Google Sheets, or CSV. The tool is free forever, needs no account, and nothing you paste is ever stored.

Why it's better than httpstatus.io

  • SEO signals built in — page title, meta robots, and canonical URL for every live page. httpstatus.io only shows status codes.
  • Noindex detection — filter instantly for pages search engines are told to ignore. A backlink on a noindex page is a wasted backlink.
  • Check history — every run is remembered, and the next check tells you what got fixed and what newly broke.
  • Honest bot-block labeling — pages behind bot protection are marked Needs verify, never misreported as plain 403s.
  • Issues grouped by domain — see at a glance which domains need your attention instead of scrolling hundreds of rows.
  • 1,000 URLs, free, no signup — with a gentle mode that paces requests so you don't get rate-limited.

HTTP status codes, explained

Every time a browser — or this tool — requests a URL, the server answers with a three-digit status code. The first digit tells you the category; the rest give the detail. Here's what the codes you'll meet in your reports actually mean:

2xx Success — the page is alive

200
OK — the page loaded fine. This is what you want for every important URL.
201
Created — a new resource was created. You'll mostly see this on APIs, not web pages.
204
No Content — success, but nothing to show. Rare on normal pages.

3xx Redirection — the page moved

301
Moved Permanently — the page now lives at a new URL, forever. Link equity passes, so update your links to the final URL.
302
Found (temporary) — a temporary move. Don't use it for permanent moves; search engines keep the old URL indexed.
307
Temporary Redirect — like 302, but preserves the request method. Temporary.
308
Permanent Redirect — like 301, but preserves the request method. Permanent.

4xx Client errors — something's wrong with the request or the page

400
Bad Request — the URL or request is malformed.
401
Unauthorized — the page needs a login first.
403
Forbidden — the server refuses to answer. Often bot protection rather than a real dead page, which is why this tool double-checks before reporting it.
404
Not Found — the page doesn't exist. Fix the link, redirect it, or remove it.
410
Gone — deliberately removed, permanently. A stronger removal signal than 404; search engines drop it faster.
429
Too Many Requests — you're being rate-limited. Slow down (try Gentle mode) and check again later.

5xx Server errors — the website itself is broken

500
Internal Server Error — the server crashed handling the request. The site owner's problem to fix.
502
Bad Gateway — the server's upstream service failed.
503
Service Unavailable — temporarily down or overloaded. Worth re-checking later.
504
Gateway Timeout — the upstream server took too long to respond.

SEO tips: use 301 (not 302) for permanent moves so rankings transfer; use 410 instead of 404 when a page is deliberately removed so Google drops it faster; and never build links to pages that return noindex — use the Noindex filter above to catch them.
